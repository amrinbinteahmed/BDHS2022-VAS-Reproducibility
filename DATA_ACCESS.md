# BDHS 2022 data access

This project uses the Bangladesh Demographic and Health Survey (BDHS) 2022 **children recode (KR)** dataset, file identifier **BDKR81FL**.

1. Visit the [DHS Program data portal](https://dhsprogram.com/data/available-datasets.cfm).
2. Register or sign in to a DHS Program account.
3. Request access to the Bangladesh 2022 DHS dataset for your research purpose, following the DHS Program's applicable terms.
4. After approval, download the children recode (KR) file in a format compatible with your local analysis workflow.
5. Keep the raw microdata outside the public GitHub repository and update local input paths in the analysis scripts.

The original microdata are subject to DHS access conditions. This repository intentionally does not redistribute them. Access approval and availability are determined by the DHS Program.
